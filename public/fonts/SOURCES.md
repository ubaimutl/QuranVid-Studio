# Bundled fonts

Downloaded unmodified from Google Fonts on 24 October 2026. Each family is distributed under the SIL Open Font License; the original license notices accompany the font files in this directory.

- DM Sans: https://github.com/google/fonts/tree/main/ofl/dmsans
- Noto Naskh Arabic: https://github.com/google/fonts/tree/main/ofl/notonaskharabic
- Amiri Quran: https://github.com/google/fonts/tree/main/ofl/amiriquran
- Amiri: https://github.com/google/fonts/tree/main/ofl/amiri
- Scheherazade New: https://github.com/google/fonts/tree/main/ofl/scheherazadenew
- Lateef: https://github.com/google/fonts/tree/main/ofl/lateef

The Arabic font files were checked against every non-whitespace codepoint in the bundled 6,236-verse Uthmani text dataset. All five cover all those codepoints. Browser rendering and font loading are also checked in the editor's browser tests. No glyph-code substitutions or changes to Quran text are made when switching fonts.
