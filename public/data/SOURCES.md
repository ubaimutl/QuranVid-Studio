# Quran content provenance

Retrieved on 24 October 2026 from the Quran.com public v4 API.

- Arabic Uthmani text: https://api.quran.com/api/v4/quran/verses/uthmani
- English translation, resource 20 (Saheeh International): https://api.quran.com/api/v4/quran/translations/20
- Chapter names and counts: https://api.quran.com/api/v4/chapters?language=en
- Sample recitation timings: https://api.quran.com/api/v4/chapter_recitations/7/1?segments=true
- Sample recording: https://download.quranicaudio.com/qdc/mishari_al_afasy/murattal/1.mp3

The Arabic text is preserved as returned by the API. Translation footnote markers and HTML tags are removed for display; commentary is not bundled. Arabic and English datasets each contain 6,236 ordered entries. All 114 chapters are included.

Sample verse timing boundaries are copied in milliseconds from the chapter recitation response and converted to seconds. These timings belong to this specific recording and must not be assumed to fit uploaded recordings.

Content is attributed to its original providers. Its availability through an API does not assign an application-code license to the text, translations, fonts or recordings. Review the providers' applicable distribution and usage terms before public release.

## Prepared recitation catalog

`recitations/catalog.json` and its per-reciter chapter files are generated by `scripts/prepare-recitations.mjs` from authenticated Quran Foundation Content API responses. The catalog records its environment and preparation date. Chapter reciter IDs come from `/resources/chapter_reciters`; audio files and timing boundaries come from `/chapter_recitations/{reciter_id}/{chapter_number}?segments=true`. Only public MP3 URLs without query credentials and complete, validated chapter timing tables are included. OAuth tokens and client credentials are not included. The original recording timestamps are converted from milliseconds to seconds without estimation. Audio is fetched only when the user imports a selection.
